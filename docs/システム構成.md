## このシステムは何か

Windows 11 用のデスクトップアプリ。画面は WPF（WebView2）、タスク・履歴・実行処理は Rust。プロジェクトとタスクの管理、Codex／Claude Code への依頼と承認、ニュース巡回（タスク KAGARI-AI-News）、SHIRANUI の監視状態とアラートの表示など。使い方の詳細は README.md。データは `%LOCALAPPDATA%\RustAIWorkspace\workspace.tsv`。2026-11-25 に `os\kagari\` へ移した。
