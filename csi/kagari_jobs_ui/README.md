# KAGARI 生成AI案件 UI改善パッケージ

## 目的
案件比較を優先し、長文は選択行の詳細ペインへ移す。既存の黒いヘッダー、オレンジのアクセント、ナビゲーション、ピン留め、巡回機能を維持する。

## 同梱物
- preview/redesign.png : 1600×960の画面モックアップ（静的、参考表示）
- icons/ : 14種の24×24 SVGアイコン（線画、色変更可能）
- tokens.json : 色定義
- wpf/JobsResources.xaml : WPF Brush、Geometry、基本Style
- implementation.md : Codex向け仕様・受入条件

## 注意
元のソースコードにはアクセスしていないため、本パッケージは設計・素材であり既存アプリへの適用済みコードではない。モックアップの案件名は短縮例。件数8、新着1、ピン2は画像で確認できる表示に基づく参考値。巡回の4/11と一覧7件、画面右の8件は元画像で不一致のため、実装では計測時点・定義を明示すること。SVGとXAMLはWindows上での表示未検証。
